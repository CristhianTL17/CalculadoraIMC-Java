# Body Mass Index (BMI) Calculator

This is a simple Java program that calculates the Body Mass Index (BMI) based on the user's weight and height. It then categorizes the result into different ranges such as underweight, normal weight, overweight, and obesity.

## How to use

1. Download the project files.
2. Compile and run the `BMI_Calculator.java` file.
3. Enter your weight (kg) and height (m).
4. View your BMI and category result.
